# Preserved local variants

The root preserves the universal integration factory checkout. `local-checkouts/micro-integration-factory` preserves the workbench variant, including its schema library changes. `local-checkouts/agentic-integration-factory2` preserves the source-specific generation variant. These snapshots retain divergent local work without replacing one version with another.

Secrets, local runtime files, dependencies, compiled bundles, and generated caches are excluded.
