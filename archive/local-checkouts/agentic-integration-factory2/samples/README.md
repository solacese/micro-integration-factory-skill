# Samples

Bundled local demo inputs for the agentic integration factory.

## Included

- `openapi/stripe-webhook-demo.yaml`
  - the prepared Stripe webhook contract used for the later Stripe micro-integration run
- `openapi/petstore.yaml`
  - a generic OpenAPI reference sample kept for exploration and comparison

## Intended Use

The prepared env files in the repo point to these local sample assets so the standalone repository no longer depends on files from a different workspace.
